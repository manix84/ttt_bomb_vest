# 🔒 Privacy

## 🧨 Bomb Vest Addon

`[TTT] Bomb Vest` does not collect, store, transmit, or sell personal data.

## 🎮 In-Game Data

The addon only uses normal Garry's Mod and TTT game state while a server is running, such as player entities, names, positions, health, and round state. This data is used locally on the server for gameplay features like explosion damage and bomber stats.

The addon does not send gameplay data to any external service.

## ⚙️ Configuration

Server and client preferences are stored through Garry's Mod ConVars. These settings stay in the normal Garry's Mod/server configuration environment.

## 🚀 GitHub Actions

Release and deployment workflows run in GitHub Actions. Steam Workshop deployment uses repository secrets provided by the repository owner, such as Steam authentication details. Those secrets are not part of the addon and are not exposed to players.

## 📬 Contact

For privacy questions or issues, use the project repository or Steam Workshop page.
